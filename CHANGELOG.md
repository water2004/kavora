# Changelog

## Unreleased — Minecraft 26.3 port

- Vulkan-only rendering with one shared device and the runtime presenter.
- Java 25 FFM SDK, matching custom Remix C API 1.5.0.
- Required external Sodium terrain capture and video settings.
- Iris-derived visual settings, editable quality presets and separate DLSS controls.
- Volumetric atmosphere, clouds, night sky and Caustica-Horizon-derived End visuals.
- Revised material, particle motion, transparency and block-damage capture.
- Optional Remix Horizons voxel terrain add-on with persistent observed-terrain cache.
- Source organized into the four named components with per-component licensing.

The original NVIDIA project's 1.21.1 release history belongs to its upstream
repository. This log records the community port rather than promising that
upstream installers or binaries work with it.
