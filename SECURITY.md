# Security

This is a community-maintained port, not a repository managed by NVIDIA.

For a vulnerability in this project's modifications, use GitHub's private
vulnerability reporting if the repository has it enabled. Ordinary rendering
bugs and crashes belong in the issue tracker. Do not post account tokens,
private worlds or unredacted process dumps publicly.

For an issue in an unmodified NVIDIA SDK, driver, or upstream runtime, use
the relevant vendor's security reporting channel. Include the affected
component version and a minimal reproduction.
